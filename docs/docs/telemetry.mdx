# Telemetry removed in this fork

This build does not record usage events or activity in the telemetry database and does not send analytics, opt-out notifications, or diagnostic install pings. The legacy `telemetry:enabled` setting and reporting RPCs remain compatible but cannot enable collection. Existing databases are preserved.

Wave AI, BYOK, local models, and ChatGPT / Codex subscription use do not depend on telemetry. Explicit AI requests go to the selected provider; software update checks are a separate feature. Codex runs with analytics, feedback collection, and OTEL exporters disabled.

See [setup and privacy notes](https://github.com/S1eezer/waveterm/blob/main/docs/CHATGPT-AND-REMOTE-DESKTOPS.md) for account security, local conversation history, and supported features. The legacy telemetry document describes upstream historical behavior, not this build.
